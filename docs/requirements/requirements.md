# 要件定義書

**複数アカウント切替メッセージアプリ（Orto）**

- 本書の位置付け：プロダクトの目的・スコープ・非機能要件を定義する。各機能の挙動は[機能仕様書](../specs/functional-spec.md)を正とする
- 本書のMVPは、最初の公開版であるv1.0を指す

---

## 1. 目的

Ortoは、1台の端末で複数のアカウントを切り替えて使える、独自実装のメッセージアプリである。既存のSNSやメッセージアプリの通知を集約するツールではない。

- **コアバリュー**：用途や相手に応じてアカウントを使い分け、アイコンのタップで即座に切り替えられること
- **守るべき前提**：同じ人が持つ複数のアカウントが、他の利用者から結び付けられないこと
- **目指す姿**：ストアで一般公開し、多数の利用者を獲得する。認証コスト・インフラ・不正利用対策・収益化は、利用者の増加を前提に設計する

---

## 2. 用語

| 用語 | 定義 |
|---|---|
| ユーザ | 電話番号に1:1で紐づく認証主体（uid）。内部の概念で、他の利用者には見せない |
| アカウント | ユーザ配下に複数作成できる、他の利用者から見えるプロフィールの単位。友だち追加・メッセージ送信の主体 |
| アカウントID | アカウントごとの、利用者が入力・検索・共有するID。作成後は変更できない |
| 友だち | あるアカウントが追加した相手のアカウント。片方向の関係で、相互の追加は必須としない |
| トーク | 2つのアカウント間の1対1のやり取り |

## 4. スコープ

### 4.1 MVP（v1.0）

| 分類 | 要件 | 機能仕様書 |
|---|---|---|
| 認証 | 電話番号のSMS認証でログインする（メールアドレス認証は提供しない）。ログイン状態は起動時に引き継ぐ | 4.1.1 |
| 認証 | 電話番号を、uidを変えずに変更できる。任意の引き継ぎパスワードで、新しい端末からのログインを保護できる | 4.1.3・4.1.4 |
| 認証 | アプリ内から退会できる（ユーザと全アカウントを削除する） | 4.1.5 |
| アカウント | 1ユーザにつき2件まで作成し、タップで即座に切り替える。アカウントごとの未読数を確認できる | 4.2.1・4.2.2 |
| アカウント | アカウントを削除できる（相手には「退会済みアカウント」と表示し、トーク履歴は残す）。削除したアカウントIDは再利用できない | 4.2.3 |
| アカウント | アカウントごとに4桁のパスコードロックを設定できる | 4.2.4 |
| 友だち | アカウントID検索・QRコード・招待リンクで友だちを追加し、一覧で見られる。友だちにニックネームを設定できる | 4.3.1〜4.3.3・4.3.5 |
| 安全対策 | 相手をブロックできる。相手のアカウント・メッセージを運営者に通報できる | 4.3.4・4.3.6 |
| 安全対策 | 友だちでない相手からのトークは、トークリクエストとして分けて表示する。友だち追加するまで返信できない | 4.4.2 |
| 安全対策 | ID検索で見つかるかどうかをアカウントごとに選べる | 4.5.1 |
| チャット | トーク一覧（最新メッセージ・未読数）と、未読合計のバッジを表示する | 4.4.1 |
| チャット | 1対1でテキスト（2000文字まで）と画像（1回に1枚、キャプションなし）を送受信し、既読を表示する | 4.4.3・4.4.4 |
| チャット | メッセージにリアクションできる。コピー・自分の画面からの削除・送信取消ができる | 4.4.5 |
| 通知 | 新着メッセージとリアクションをプッシュ通知で受け取る。アカウントごとにオン・オフできる | 4.4.6・4.6.1 |
| プロフィール | 表示名・一言コメント・プロフィール画像・背景画像を編集できる | 4.5 |
| 設定 | 表示言語（日本語・英語）と画面モード（ライト・ダーク・端末に合わせる）を選べる。問い合わせと規約の閲覧ができる | 4.6.2・4.6.3 |

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| 公開形態 | ストアで一般公開する。MVPは無料で、アプリ内課金は含まない |
| プライバシー | uidや電話番号など、同一人物と分かる値を他の利用者に見せない。他の利用者が読めるデータにも含めない |
| プライバシー | 通知には固定文言だけを表示し、送信者・本文・絵文字を含めない |
| セキュリティ | アカウント数の上限・予約ID・ブロック中の送信拒否などの制約は、アプリではなくサーバー側のルールで保証する |
| セキュリティ | App Checkで、公式アプリ以外からのアクセスを拒否できるようにする（iOSは強制済み。Androidは今後） |
| 不正利用・コスト | SMSの悪用に備えて、送信できる国・地域を制限する。費用の急増は予算アラートで検知する |
| 運営 | 通報は運営者が確認し、必要に応じて利用規約に基づき利用を制限・停止する |
| 法令・ストア審査 | 利用規約とプライバシーポリシーを公開する。App Storeの審査ガイドラインが求める、アプリ内の退会（5.1.1(v)）とブロック・通報（1.2）を提供する |
| データの保存 | 保存期間と削除の扱いは公開しているプライバシーポリシーに従う |
| 多言語 | 日本語・英語に対応する |
